# MJ 蜘蛛侠特效（Edge 个人版）

在网页搜索框、评论区、文本框或其他可编辑区域中输入 `mj`，扩展会随机播放样例中的两种卡通蜘蛛侠摆荡特效，并播放对应声音。匹配不区分大小写，输入的 `mj` 会原样保留。

## 安装到 Edge

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目中的 `extension` 文件夹。
5. 打开一个普通网页，在搜索框或文本输入区域输入 `mj` 测试。

扩展不能运行在地址栏、Edge 设置页、扩展商店和其他浏览器保护页面中。首次安装后，已经打开的网页需要刷新一次。

## 使用设置

点击 Edge 工具栏中的扩展图标，可以：

- 暂停或启用特效
- 开启或关闭声音
- 随机播放两种动效，或固定播放其中一种

## 在 VS Code 中开发

用 VS Code 打开本项目根目录 `MJ`。代码为原生 JavaScript，不需要编译。修改 `extension` 内的文件后：

1. 在 VS Code 中运行任务 `MJ: 运行检查`。如果本机另有 Node.js，也可以在终端执行 `npm run check` 或 `pnpm run check`。
2. 回到 `edge://extensions/`，点击此扩展卡片上的刷新按钮。
3. 刷新用于测试的网页。

## 项目结构

```text
extension/              可直接加载到 Edge 的扩展
  assets/               两种透明动画和对应音频
  icons/                扩展图标
  lib/detector.js       mj 匹配规则
  content.js            输入监听与动效播放
  background.js         iframe 转发与声音状态
  popup.*               设置面板
sample/                 用户提供的原始样例
scripts/                素材构建与结构验证脚本
tests/                  输入匹配自动测试
SPEC.md                 已确认的产品与技术规格
```

## 重新生成素材

素材已经随扩展提交，正常使用不需要重新生成。若要从原始样例重新处理，需要 Python（Pillow、NumPy）和 FFmpeg：

```powershell
python scripts/process_assets.py --ffmpeg "C:\path\to\ffmpeg.exe"
```

## 隐私

扩展完全在本地运行，不访问服务器，不记录或上传网页内容。检测时只检查当前光标之前、识别 `mj` 所必需的字符。密码框、只读输入框和非文本控件不会触发。

## 素材说明

本项目当前使用由用户提供样例中提取的角色画面和声音，仅作为个人本地原型。公开分发、商业使用或提交扩展商店前，需要重新确认相关角色形象及音频的授权状态。
